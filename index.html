USB / Bluetooth COM-port bridge

SELECT TRANSPORT

Choose how your ESP32 is connected when you start the Windows bridge: USB cable (USB Serial) or Bluetooth (Classic SPP). The bridge lists the available Windows COM ports so you can select the correct one.

TransportUSB Serial or Bluetooth SPP
Bridge statusWaiting for Firebase data
Run py bridge\smartshoe_bridge.py from the downloaded project folder. In the terminal, choose 1 for USB cable or 2 for Bluetooth, then select the COM port from the detected list. For Bluetooth, choose the Windows outgoing COM port. GitHub Pages cannot directly open Windows COM ports, so this small local bridge is required.
